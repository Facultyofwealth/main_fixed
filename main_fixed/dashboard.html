Help Center

Recently asked questions from churches using In the Beginning AI.

Can I use the phone remote while live transcription is running?

Yes. The mobile remote and live transcription run independently, so you can control verse display from your phone while the AI continues detecting scripture in the background.

Does it work offline?

Bible search, verse display, and the mobile remote can work offline. Online transcription needs internet access, while offline Whisper mode processes audio locally on the server machine.

How accurate is verse detection?

Direct references like John 3:16 are detected quickly. For paraphrases or partial quotes, the semantic search engine compares against the Bible text and returns the closest scripture matches.

What happens if the internet connection drops?

Live cloud transcription pauses until the connection returns, but manual Bible search and verse display continue to work. Pre-loading key verses before service is recommended.

Where are sermon transcripts stored?

Transcripts are stored locally on your device. Online transcription streams audio only for processing, and generated notes use transcript text only when that feature is requested.
